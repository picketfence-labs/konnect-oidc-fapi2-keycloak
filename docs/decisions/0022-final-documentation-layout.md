# ADR 0022: 最終デモ構成に合わせた資料の整理

- 状態: 採用済み（2026-10-13に全体構成図を利用者確認済み）
- 日付: 2026-10-13

## 背景

WP1～WP6の受入後も設計一覧に実装待ちの記述と実行前プレビューが残っていた。利用者は日本語化、不要ファイル削除、全体構成図とアーキテクト向け説明の追加を依頼した。Route A/B図は全体構成図の確認後に更新する指定がある。

## 決定

`ARCHITECTURE.md`を全体説明の入口とし、設計一覧から現行契約・受入結果・履歴へ案内する。説明文と見出しを日本語に統一し、製品名、識別子、コマンドは維持する。

実行前プレビュー5件を`docs/design/verification-history.md`へ統合し、受入結果、失敗試行、receipt識別情報を残す。古い一回限りの起動・承認手順を削除する。試験harness、ADR、最終受入表と一次証跡は維持する。

`docker-compose.demo-native.yml`は受入済みApple Silicon構成の再現に必要なため残す。reset/logout図のJSON・HTML・PNGと参照を削除する。logoutの実装と操作手順は維持する。

全体構成図を先に作成し、利用者確認後にRoute A/BのJSON・HTML・PNGを更新する。利用者とAPI Gatewayの間へ3rd Partyのswimlaneを追加する。その内部へKong Gatewayと3rd Partyサービスを配置する。

2026-10-13に全体構成図の利用者確認を受け、Route A/Bの改訂を完了した。各図の生成物検査、ブラウザー検証、画像レビューをreceiptへ記録する。公開済みPagesは旧版であり、今回のローカル改訂版と区別する。

## 影響

現行説明から未完了時点のプレビューへ誤誘導することを防ぐ。履歴は当時の結果として読み、失敗receiptを成功へ書き換えない。外部公開、Control Plane適用、Docker変更は伴わない。
